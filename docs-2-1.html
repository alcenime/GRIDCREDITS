01 / INTRODUCTION

What is GridCredits?

GridCredits is an NFT ecosystem built around modular characters created from a simple grid language. Every character is assembled from the same visual system: squares, blocks, and repeating structure. The result is a collection of characters that look related to each other while remaining distinct.

The characters are not intended to exist only as collectibles. A GridCredits character can also participate in the GridCredits economy through two mechanisms: EARN and BURN. Both of them lead to the same place, the $GRIDS token.

The core idea

The central idea of GridCredits is that a character is more than an image. The NFT you hold is your character inside the ecosystem, and what happens to that character is a choice that belongs to you.

A GridCredits character can be:

  • Collected. Held as a character and as a collectible.
  • Activated. Put to work through the EARN page.
  • Used to earn. An active character generates $GRIDS according to the active earning rules.
  • Permanently burned for $GRIDS. The NFT is removed and $GRIDS is received according to the active burn rules.

These options are not a sequence you are required to follow. Keeping a character as a collectible is a valid choice, and so is earning with it, and so is burning it. This documentation describes each of them, how they relate to each other, and where the exact parameters come from.

How to read this documentation

The sections that follow move from the character itself, to the token, to the two ways of earning, and finally to the way the whole system fits together. A user flow, a section on rules and parameters, and a FAQ close the document. Where a value or requirement has not been finalized, this documentation says so directly rather than guessing.

02 / GRIDCREDITS NFT

The Character

A GridCredits NFT represents a single character. Holding the NFT means holding that character: it is yours, it is identifiable as its own piece, and it stays in your collection for as long as you keep it.

Ownership

Ownership is the starting point of everything in the ecosystem. The mechanics described in this documentation are available to the holder of a GridCredits NFT. Connecting a wallet that holds a character is what allows the site to show you the characters you own on the EARN and BURN pages.

Character identity

Each character is built from the modular grid language that defines the collection. That shared language is what makes GridCredits characters recognizable as a family. Each NFT is its own character, and nothing in the ecosystem asks you to treat it as anything other than an individual piece.

The collectible aspect

A GridCredits NFT is a collectible first. It can remain a collectible in your wallet for as long as you like, without being activated and without being burned. Nothing about the earning or burning mechanics changes the fact that a character is a piece you can simply hold.

Role inside the ecosystem

Alongside being a collectible, the NFT is your access point to the ecosystem. It is what you activate when you want to earn, and it is what you select when you want to burn. In both cases the NFT is the thing the mechanics act on.

  • NFT ownership and earning. To earn, you own a character and activate it through the EARN page. The NFT stays in your collection while it earns.
  • NFT ownership and burning. To burn, you select a character you own on the BURN page. Burning permanently removes that NFT from your collection.

The NFT can therefore remain a collectible while also participating in the ecosystem. Participation through earning does not remove the character. Only burning does.

06 / TWO WAYS TO EARN

Earn or Burn

GridCredits gives a character two ways to produce $GRIDS. They are separate mechanisms, and the most important difference between them is what happens to the NFT.

Earn with your character

Own and activate a character. The character participates in the earning system and generates $GRIDS according to the active earning rules. Throughout this process the NFT stays with you.

Burn your character

Permanently burn the NFT and receive $GRIDS according to the active burn rules. This happens once. After it, the NFT no longer exists in your collection.

OPTION 01

EARN

KEEP THE NFT.

The character is activated and participates in the earning system. It remains in your collection.

OPTION 02

BURN

PERMANENTLY REMOVE THE NFT.

The character is burned. It is removed from your collection and $GRIDS is received.

Which of the two to use is up to the owner. This documentation does not recommend one over the other.

08 / USER FLOW

From Character to $GRIDS

The following is a conceptual user journey. It shows how the pieces described in this documentation fit together from a user's point of view. It contains no figures, because none are defined here.

  1. A user acquires a GridCredits NFT.
  2. The user connects their wallet.
  3. The character becomes visible on the EARN page.
  4. The user activates the character.
  5. The character participates in the earning system.
  6. The user accumulates $GRIDS.
  7. The user can continue using the character.
  8. Alternatively, the user can choose to burn the NFT.
  9. After burning, the NFT is permanently removed.
  10. The user receives $GRIDS according to the active burn rules.

Steps 3 to 7 describe the earning path and steps 8 to 10 describe the burn path. This is a conceptual flow: a user can stop at any point, and a user who never activates or burns simply keeps a collectible.
